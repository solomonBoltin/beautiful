    The score is Σ wₖ·goodnessₖ spread over 1–100. Every factor descends from a paper (Birkhoff 1933, Ngo 2003, Reinecke & Gajos 2013, Miniukovich & De Angeli 2015, Cohen-Or 2006, Hasler & Süsstrunk 2003…). No model weights, no dataset, no network call for the image. First load fetches numpy, scipy and pillow (~25 MB) via Pyodide; cached afterwards. Same numbers as pip install beautiful-score.
